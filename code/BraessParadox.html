Equations and assumptions
Minimize: C = c₁P₁ + c₂P₂
Generation: 0 ≤ P₁ ≤ G1 max, 0 ≤ P₂ ≤ 1200 MW
Balance: P₁ + P₂ = Load
DC flow: Fᵢⱼ = (θᵢ − θⱼ) / Xᵢⱼ
Feasibility: |Fᵢⱼ| ≤ line limit, with the connected and removed topologies solved separately.

A lossless DC approximation with fixed voltage magnitudes. Line reactances are relative weights (1 on the main lines, 0.2 on the tie); a common scale is absorbed into the angles. Voltage limits, reactive power, and contingencies are outside this example.
